1核心理念：一句话读懂整套体系

模块一 · 理论基础 | 所有知识的地基

顺国家意志而为 · 逆散户人性而行

这句话是整套《牛市生存手册》的灵魂。理解它，就等于拿到了打开所有模块的钥匙。

🔑 "顺国家意志"：跟谁站在一边？

A股市场带有鲜明的政策属性。国家想让你赚钱的方向，往往有持续的增量资金、产业扶持和估值抬升；而国家正在压制的方向（比如疯炒、过热、泡沫），无论散户多狂热，最终都会被"压"下来。手册中的判断：

  • 慢牛才是国家要的——疯牛涨太快会透支经济转型成果，所以"三步一回头"的慢牛反而是健康的；
  • 监管双向管控——跌多了有人托（国家队托底、政策救市），涨多了有人压（上调保证金、窗口指导"控温"）；
  • 方向跟着会议走——重要会议定方向 → 部门文件抓落实 → 资金流向验证 → 产业链传导。

😈 "逆散户人性"：和谁对着干？

散户的典型行为：大涨时贪婪追高、大跌时恐惧割肉、套牢后侥幸死扛、亏钱后报复性交易。手册反复强调"别人贪婪我恐惧，别人恐惧我贪婪"，以及一条最重要的纪律：

⭐ 卖在上涨时，买在下跌处。大涨大卖，不追求最高点，只追求相对高位；大跌不恐慌，分批买入优质筹码。
📖 早课故事（2024/10/8）：国庆节后首个交易日，市场情绪极度亢奋，无数人在集合竞价阶段直接挂涨停价"抢筹"，结果当天高开低走，追高者当日浮亏超 10%。这正是"顺散户人性"（追涨）的代价——情绪最热的时候，往往是风险最大的时候。
💡 给初学者的第一个作业：下次你想"冲进去买"或者"慌着割肉"的时候，先停下来问自己——我现在的决定，是顺着大多数人的情绪，还是逆着它？

📊 量能辅助判断：地量见地价

除了年份，成交量也能帮助判断大底大顶：

  • 地量缩至前期高点成交量的 1/2 → 多为反弹；
  • 地量缩至前期高点成交量的 1/3 → 大概率是反转。
📖 早课故事（量能案例）：2015/9/30 万得全A成交约 3700 亿元，约为前期高点 1.2 万亿的 1/3，随后市场反弹了约 3 个月；2024 年 9 月市场成交萎缩至约 5000 亿（对比峰值 1.2 万亿），同样处于"地量区"，随后迎来政策驱动的大反攻。另外手册还提到干支推背：2026 丙午年"食神生财，股市普涨"，2028 戊申年"七杀偏印，普跌"——作为趣味参考，别当预言用。
⚠️ 边界提醒：年份规律是"统计+玄学"的经验总结，只能定基调，不能定买卖点。真正执行买卖，要看技术信号（第二部分）和操作系统（第四部分）。

🎯 格兰维尔八大买卖法则（核心中的核心）

手册高度推崇这套 1960 年代的均线交易法则——因为它把"什么时候买、什么时候卖"翻译成了可执行的规则：

类型编号信号描述
买入买①均线走平/上升，股价从下方突破 → 买入
买②股价跌破上升均线后快速收回 → 加码买入
买③股价下跌未破均线，重现升势 → 买入
买④股价跌破均线且远离均线 → 短期反弹机会
卖出卖①均线走平/下降，股价从上方跌破 → 卖出

🧩 均线形态速查

  • 井型：5/10日平行上穿20/30日 → 买入信号；
  • 死亡谷：10/20/30日围成尖头朝下的三角 → 见顶下跌；
  • 银山谷 / 金山谷：10/20日上穿30日，两次确认后为金山谷 → 主升浪；
  • 金蜘蛛 / 毒蜘蛛：5/10/20日同时金叉 / 死叉于一点；
  • 多头 / 空头陷阱：均线假突破诱多/诱空，多出现在行情初期。
💡 实战要点：手册中最常用的简单规则是——20日均线是强弱分水岭。指数站上 20 日线且量能配合 → 偏多思维；跌破 20 日线且 3 日收不回 → 降低仓位（见第 20 章决策规则）。

7成交量：一切信号的"验钞机"

模块二 · 技术分析（源：第39–41期）| 量在价先

技术分析里有一句老话：量在价先。成交量反映买卖双方的分歧程度——放量说明分歧大、有人抢着买也有人抢着卖；缩量说明大家意见一致（要么惜售，要么无人问津）。手册把量价关系做成了九宫格口诀：

价格＼量能放量平量缩量
上涨机会多，但顶部要防守能维持，起点终点有量变难维持，下跌末期多关注
横盘有矛盾，天量等未来升冷淡市，横久必跌无行情，只等后续好球区
下跌不接刀，除非历史大底淡后市，下跌中继少参与是调整，地量地价可以等

8MACD：趋势与动能的"仪表盘"

模块二 · 技术分析（源：第20、42–43期）| 最常用的摆动指标

MACD 由三条线组成：DIF（快线）、DEA（慢线）和红绿柱（动能）。0 轴是"春夏/秋冬"的分界线——手册铁律：只投 0 轴上方，0 轴上方是春夏行情，下方是秋冬行情。

图 8-1 · MACD 结构示意：金叉死叉 + 0轴 + 红绿柱（示意，非真实行情）

🚦 五大核心战法

  1. 顶背离卖，底背离买：股价创新高但 MACD 高点降低 = 顶背离（动能衰竭）→ 卖；股价创新低但 MACD 低点抬高 = 底背离 → 买。日线和 60 分钟线的背离最有操作价值。
  2. 二次金叉坚决买，二次死叉坚决卖：0 轴附近的第一次是"试盘"，第二次才要果断出手。
  3. 只投 0 轴上方：0 轴上方为春夏（做多季节），下方为秋冬（休息季节）。
  4. 风洞买入法：MACD 先死叉后快速金叉，红柱快速放大形成"网兜" → 买入。
  5. 红绿灯：红柱最长开始缩短 → 短线顶；绿柱最长开始缩短 → 短线底。

🔗

周期识别特征应对
强势周期量能大、指数>20日线、多头排列大部分资金布局中线方向 + 短线热点 + 留备用金

👁️ 趋势判断三重境界（新手只练第一重）

  • 第三重（细节）：分时线，不适合大多数人，容易迷失在噪音里。

⚖️ 操作系统权重因子（你的"扣分项"在哪？）

100% = 趋势判断30% + 行业选择20% + 操作管理20% + 风险控制20% + 资金管理10%

📖 早课故事（稳健系统）：手册建议只做两类行情——大级别牛市（年份尾数 5/6/7/9 + 政策拐点 + 30日线多头）和结构牛（如 2019 年新能源行情）。核心心法是"只吃鱼身，弱水三千取一瓢"——不追求从鱼头吃到鱼尾，赚到中间最稳的一段就够了。

23顺势而为：让趋势替你赚钱

北大炒股公开课（源：26.05.26）| 稳定盈利的核心要诀

顺势而为四个字人人会说，但真正理解的人不多。北大课给出的精确定义：顺势不是"涨了就买"（那是追涨），而是在趋势已经形成之后，站在趋势一侧，并在趋势未被破坏之前持续跟随。

📡 趋势从哪里来？三维共振

💧
资金

资金在流入还是流出？

🏗️
结构

结构在强化还是弱化？

🎈
情绪

情绪在扩张还是收缩？

三者同向，就形成趋势。所以顺势的核心不是预测未来，而是承认现实——承认趋势已经发生，而不是预判趋势即将发生。

顺趋势，你的错误都是暂时的；
逆趋势，你的正确也是暂时的。

🔄 千金难买牛回头

在成长股或强趋势行情中，股价持续上涨必然带来回调。很多人把回调当风险，但从趋势角度看，强趋势中的回调是趋势的一部分，而不是趋势的反面——它是最好的参与点。

📖 早课故事（傅海棠的棉花期货）：2009年，"农民哲学家"傅海棠实地调研发现棉花价格跌破种植成本，判断涨价趋势必然来临。他用600万本金连续做多棉花，一年间利用波动持续加仓，2010年11月在极高位置平仓，离场资金1.2亿。启示不在于收益规模，而在于对逻辑本身的坚守——趋势面前，时间才是杠杆。

🌡️ 工具：均线是趋势的"温度计"

  • 均线不预测未来，只确认现在——短均线持续运行在长均线之上=上升趋势；均线走平或下弯=趋势减弱；
  • 趋势线变轨观察法：上行趋势看低点连线，下行趋势看高点连线；一段趋势中趋势线通常变轨2-3次，变轨第三次，行情基本结束；
  • 一旦趋势被破坏，继续坚持反而变成另一种形式的逆势。

🧘 顺势难在理解，更难在克制

大多数人做不到顺势，往往因为三个原因：①无法接受不是最低点买入；②无法承受持有过程中的回调；③无法在趋势结束时及时离场。顺势而为，不是做更多，而是做更少——减少无效判断，减少频繁操作，让趋势本身发挥作用。

📖 四大法则背后的"人性设计"

  • 止损要快：人天然厌恶承认错误，会主动或被动迟疑观望——止损快是对人性结构的反向设计；

25流动性压力与危机：仓位主动权

牛市生存手册（源：26.06.10）| 不同环境，不同仓位策略

很多人认为风险就是亏钱。其实不是——真正的风险，是在错误的时间用错误的仓位。同样是10%的调整：对满仓者是灾难，对五成仓者是一次正常波动，对两成仓者甚至可能是加仓机会。市场不会因我们的情绪改变走势，但仓位会决定我们面对市场时的情绪。

⭐ 第一原则：投资的第一步从来不是预测市场，而是管理仓位。因为预测经常会错，仓位却永远掌握在自己手里。

🌊 流动性压力：重节奏，轻方向

流动性压力的特点是：趋势还在，资金变谨慎了。AI没消失、半导体没消失、算力需求没消失——产业逻辑依然成立，变化的是资金节奏。这个阶段最容易犯两个错误：

错误根源解药
看见调整就认为牛市结束用价格判断逻辑，而不是用逻辑判断价格看支撑行情的核心逻辑是否变化，而非指数跌了多少
盲目满仓抄底路径依赖："每一次下跌都是机会"分批应对，让仓位和市场同步变化，而非和情绪同步

这两个错误看似相反，本质同源：把短期波动当成长期趋势。趋势决定方向，波动决定节奏——方向错了要认错，节奏乱了要调整。

🚨 流动性危机：重生存，轻收益

压力是价格问题，危机是信用问题。2008年金融危机中很多优质公司基本面没问题，但因为市场缺钱，所有资产一起跌——此时市场不再讨论价值，而是在争夺现金。现金为王：现金不仅意味着安全，更意味着未来的选择权，让我们有资格活到下一轮机会出现。

🧭 四状态仓位应对框架

市场状态识别特征仓位应对
① 流动性宽松均线重新向上、风险偏好提升保持较高仓位，重点参与趋势
② 流动性压力趋势未破、波动加大、成交萎缩中性仓位、保留现金，控制节奏分批应对，永远留有余地
③ 流动性危机信用恶化、所有资产同步下跌、资金踩踏降低仓位、提高现金比例，保存实力
④ 危机结束利率降低、货币重新宽松、市场转机将实力转为仓位的时机
⚠️ 关键认知：压力与危机相伴相生，市场从不提前告诉我们答案。成熟投资者不采用非黑即白的判断，而是用动态仓位保留主动权——判断错时，仓位不会让自己出局。
💡 一句话总结：我们投资最大的优势，不是买在最低点，而是在看对方向之后，还有能力一直留在牌桌上。

26策略无绝对优劣：组合思维与存活

牛市生存手册（源：26.07.01）| 停了的钟，一天也能准两次

市场风格极端分化时，每个策略都会让人不舒服：均衡策略稳健但慢半拍，风口策略弹性高但波动剧烈，长期不动策略偶尔在周期切换中"准一次"。涌哥用一个比喻点破本质：一只停了的钟，一天也能准两次——策略本身没有问题，但它面对的收益结构变了。

🕰️ 三个底层事实

  • 没有任何一种策略可以在所有市场环境中持续有效：均衡策略在震荡市稳，在结构行情反应慢；进攻策略在趋势市极强，在风格切换时回撤剧烈；
  • 市场风格分化的本质，是"收益来源结构"的切换：有的阶段收益来自广泛扩散（均衡占优），有的阶段高度集中抱团（进攻占优），有的阶段来自估值修复与现金流（红利占优）；
  • 策略是"环境适配函数"，不是绝对工具——关键问题不是它准不准，而是你的投资偏好哪种广度-深度体系、用短周期还是长周期评价。

组合模块提供什么对抗什么

⭐ 结论：市场不会奖励"持续正确"，只会奖励"长期活着"。环境的识别能力，大于策略的优劣比较——与其寻找最优策略，不如构建能让你在不同环境切换中不被淘汰的组合。

27别碰"垃圾"股：普通投资者的避险课

牛市生存手册（源：26.08.18）| 活得久，比赚得快重要一万倍

市场热度高涨时，总有人把目光投向市值小、股价低、弹性大的个股——它们涨起来一天20%比比皆是。但市场一冷，"垃圾"股死伤惨重，很多股价腰斩，而大公司相对抗跌。这里的"垃圾"股泛指：业绩模糊、市值只有几十亿、甚至有过ST经验的个股——它们常隐藏在前沿概念里，包装成"微小的潜力股"。

30四象限与三层仓位：应对式投资体系

四象限·三层仓位执行框架 + 26十月月报 | "先有价格，再有仓位"

第29章解决"什么时候换档"，本章解决一个更细的问题：当下这一周，我的仓位上限到底该是多少？答案来自一套"应对式"框架——不预测，只按价格给的信号折算仓位。

🧮 一个公式，三条线

股价 = 盈利(EPS) × 估值(PE)；
估值 ≈ 1 /（无风险利率 + 风险溢价）

三线分工：分子（盈利）和分母（利率/风险溢价）负责解释走势，趋势负责定价仓位。三条线同时恶化时（如某年九月：盈利待验 + 利率与风险溢价双升 + 趋势破位），才是真正的危险信号。

三条线看什么数据作用
分子（盈利）PE(TTM)、工业企业利润、三季报、盈利上调家数占比决定市场的上限
分母（利率/流动性）美债利率、社融/M2、M1-M2剪刀差、资金空转影响估值溢价能力
趋势（仓位开关）月线MACD、20/60日线、量价配合决定实际仓位

⚖️ 核心思维：从"观点中心"到"价格中心"

  • 先有结果，后有行为；先有价格，再有仓位——即使宏观逻辑能完美解释上涨，只要价格没确认，仓位就不提前打满；
  • 防守不是清仓，是降低主动犯错的概率，同时给犯错留出容错空间；
  • 韧性不等于进攻——政策给的是"底"，盈利验证给的才是"顶"；
  • 反弹先理解为观察窗口，其次才是进攻机会（无右侧确认时，反弹是减仓窗口）。

🎯 三步算出你的仓位上限

① 三线诊断每条线判定：改善 / 中性 / 恶化
② 四象限定位盈利强弱 × 分母改善/恶化 → 象限与风险预算上限
③ 趋势系数折算实际仓位 = 象限上限 × 趋势系数（0.4 / 0.7 / 1.0）
象限条件风险预算上限
Ⅰ 趋势进攻盈利强 + 分母改善70-80%（成长、周期、盈利加速行业）
Ⅱ 精选抱团盈利强 + 分母恶化50-65%（现金流强、低负债、确定性龙头）
Ⅲ 估值修复盈利弱 + 分母改善35-50%（红利、超跌、政策敏感方向）
Ⅳ 防守降仓盈利弱 + 分母恶化20-35%（现金、红利、资源、低波动）

趋势状态识别特征系数

31从"交易年"到"配置年"：三层配置框架

2026投资决策参考册 + 九月哑铃 + 七月分阶段操作 | 投资重心从"找机会"转向"搭结构"

同样的市场，不同的年份要用不同的打法。当"情绪修复的钱"赚完、市场进入"慢变量占主导"的阶段，频繁交易性价比下降，投资重心要从"找机会"转向"搭结构"。

🔄 为什么是"配置年"？

  • 交易年的特征：情绪波动大、板块轮动快、"抓一波就跑"有效——赚的是情绪修复的钱；
  • 配置年的特征：全球流动性不再边际放松（降息后半段）、国内政策托底但不走强刺激、经济总量偏弱但结构有亮点 → 趋势拉长、分化加剧；
  • 结论：不是熊市也不是全面牛市，而是"高波动下的结构性机会年"——估值端已不低，盈利端（分子）成为胜负手，选错赛道会很难受。

🥇 黄金与债券的定位（很多人搞反了）

  • 黄金不是短期交易品，是长期战略资产/压舱石：稳健型5%-8%，平衡型8%-12%，激进型10%-15%；回调5%-10%视为加仓机会。它承担"稳定器"而非"收益发动机"；
  • 债券不适合高收益预期：作风险对冲与波动缓冲；中短债作底仓需降低收益预期。
⚠️ 适用条件（关键）：①"配置年"的判断成立前提是流动性不再边际放松 + 政策托底但不强刺激 + 盈利待验证；②在流动性大幅宽松或单边普涨的年份，这套"重结构"的思路会显得过于保守；③三层框架的比例需按个人风险承受力确定（原文未给统一比例），且"一定是组合，不是单一押注"——这是九份策略的共同结论。
📖 选错赛道的代价：2026年的核心风险不是"没抓住机会"，而是用旧打法套新环境（追热点、重仓单一主题、忽视波动管理）、把方向判断当投资能力、情绪主导决策（高位焦虑、回撤恐慌、反复进出）。不同板块收益差距会明显拉大——A股"买对行业"有时比择时更重要。

32如何寻找卖位：三类卖出信号

26.11.04 早课 | 卖出不必抓最高点，只需识别"持有条件变了"

买入前我们研究行业、估值、走势，卖出却常常临时决定：涨了怕卖早，跌了等反弹，反弹了又等回本——于是一笔有计划的交易变成了围绕买入价格的情绪波动。

⭐ 第一原则：卖出不必以抓住最高点为目标。要识别的是——原先支持持有的条件发生了什么变化，这种变化是否已经值得降低风险。

三类卖位，分别对应三种"持有依据"的变化：趋势变了、买卖压力变了、定价依据变了。

① 跌破支撑：对应"趋势变化"

图 32-1 · 跌破支撑三步确认（示意）：不是"碰到就卖"，而是"破了且站不回"
观察对象怎么用注意事项
均线如股价多次回踩20日均线后走高，说明该线有观察价值；后来跌破且收盘站不回 → 降低风险预警均线有滞后性，趋势行情中更有效，横盘中容易反复出错
趋势线连接逐步抬高的低点；跌破后反弹无法重回原趋势、且高点开始降低 → 可能在生成新的下跌趋势线划线要用事先定好的标准，不能每跌一次就重画一条更低的线
前期平台下沿原支撑跌破后，反弹时往往转为压力关键位失守后，反弹不过即为确认
量能（辅助）放量跌破=关键位置发生大规模交易；回抽乏力再跌=转弱强化缩量下跌不能自动理解为安全
📖 案例：沪深300 周线击穿60周线与震荡区间头颈线后，价格一路向下毫无停顿，直到来到周线超长期的"国运线"才开始止跌观察。关键位失守后，趋势的"惯性"往往比想象中更强。

② 筹码集中区：对应"买卖压力"

前期成交密集的区域，聚集着被套的持有人和获利资金的交易意愿。关键不是"到了筹码峰就卖"，而是看价格进入该区域后的表现：

  • 成交明显增加、股价却难以推进、反复冲高回落 → 新增买盘正面对较强卖压 → 分批兑现；
  • 价格持续向上推进、回落又在区域获得承接 → 卖压可能被消化，不能仅因上方有大量成交就认定行情结束。
💡 用筹码图的正确姿势：筹码分布图是基于成交与换手估算的持仓成本，不是所有股东真实成本的记录。筹码帮你"制定计划"，新出现的现实因素（走不动、承接转弱）帮你"执行决策"——不要把图上某条筹码峰当成精确卖价。熊市里反弹到瓶颈就回落，常常是趋势压力 + 筹码压力同时作用。
📖 案例：机器人龙头绿的谐波，最底部筹码显示套牢区在305附近；后续反弹每次触及305都出上影线被砸落——而且这里同时是60日均线位置，双重压力。

③ 利率与盈利转弱：对应"定价依据变化"

变量如何影响股价
利率上升提高持有股票的回报要求，债券/红利更有吸引力，融资成本上升 → 市场愿意支付的估值下降；利润在遥远未来的资产（成长股）最敏感
盈利下调需求放缓、售价下降、成本提高 → 即使利率不动，业绩预期下修也会推动股价下跌
两者同向恶化估值与盈利双杀，这是最危险的组合

但不要只靠宏观判断——加一个"市场已开始重新定价"的条件：利率持续抬升后，高估值板块反复跑输、龙头反弹收不回关键位；或盈利预测不断下调、股价反弹越来越弱、前期平台被跌破。这种"出价下移"一旦开始，可能自我强化形成螺旋。

⭐ 此时的处理：影响的可能是整体风险敞口——即使某只持仓暂时没破位，也要检查和预防优质资产补跌，做事前应对或事后补救。
⚠️ 适用条件与局限（原文明确）：①这些属于交易经验规则，不能保证每次有效；②不必每次都等回抽——在更重大的扰动下（跳空下跌、流动性骤降、持有依据被明确破坏），等待"更好卖位"本身可能扩大损失；③筹码分布是估算数据，不是精确卖价；④均线类卖位在横盘震荡中容易失效（反复出现买卖信号），更适合趋势行情。

形态一：日D<20金叉 + 周J<20向上 + 月KDJ低位向上——三周期共振低位向上，坚定入场。

破壁渗透期（渗透率 <20%）——政策/技术驱动，只看 PEG，别用 PE 吓自己。

中仓（40% 左右）——短线偏弱但中线趋势仍在，降低短线仓位但不必离场。

查看答案
仓位降至 5 成以下——20 日线是强弱分水岭，破线不收回就是趋势转弱。
1️⃣1️⃣ 北大课"挣钱四大法则"中，334 仓位结构的"3-3-4"分别指？
查看答案
30%底仓（压舱石，锁定趋势）+ 30%机动仓（做波段）+ 40%现金（等机会）——核心不是收益最大化，而是任何环境下都不失去主动权。
1️⃣2️⃣ "趋势线变轨第三次"通常意味着什么？
查看答案
行情基本结束——趋势线逐级变轨（加速→震荡→掉头）后，趋势大概率进入修整或反转，顺势者应及时离场。
1️⃣3️⃣ 流动性压力与流动性危机，仓位应对的核心差异是什么？
查看答案
压力阶段重节奏轻方向（分批动态仓位，别把调整当趋势反转）；危机阶段重生存轻收益（现金为王，保存实力）。两者的共同点是：永远用动态仓位保留主动权。
1️⃣4️⃣ 三档仓位择时的两个信号分别是什么？各管什么？
查看答案
月线MACD（月末收盘确认）管"往哪走"——方向；周线MA60（周五收盘确认）管"走到哪了"——位置。两者一上一下时为均衡档。
1️⃣5️⃣ 某时处于Ⅱ象限（风险预算上限60%），趋势系数0.4，实际仓位上限是多少？
查看答案
24%（60% × 0.4）。这就是"看多但只敢用两成多仓"的算术来源——象限决定风险预算，趋势决定实际仓位。
1️⃣6️⃣ 跌破关键支撑后，什么情况才算"卖出条件成立"？
查看答案
跌破 + 回抽无法站回（收盘站不回）+ 高点开始降低，说明原持有结构已转弱。注意：遇到跳空下跌、流动性骤降等重大扰动时，不要等回抽，等待"更好卖位"可能扩大损失。
